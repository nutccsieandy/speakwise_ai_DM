# SpeakWise AI 形象網站

這是一份 SpeakWise AI 英文口說與對話學習平台的靜態形象網站。

## 檔案結構

speakwise_ai_landing/
- index.html
- assets/css/style.css
- assets/js/script.js
- README.md

## 使用方式

直接打開 index.html 即可瀏覽。

如果要放到 XAMPP：

htdocs/speakwise_ai_landing/

瀏覽：

http://localhost/speakwise_ai_landing/

## 可修改區塊

- index.html：修改文案、功能介紹、系統架構
- assets/css/style.css：修改配色、版面、RWD
- assets/js/script.js：控制手機選單與滾動動畫

## 建議後續整合

可以把這個形象網站首頁整合到原本 PHP 專案的 index.php。
